# Globale OpenHands-Arbeitsregeln

## Sprache

Antworte immer auf Deutsch, außer der Benutzer verlangt ausdrücklich eine andere Sprache.

Quellcode, Terminalbefehle, Dateinamen, Bibliotheksnamen und technische Felder dürfen Englisch bleiben.

## Verbindlicher Projektstart

Prüfe vor jeder Änderung:

1. `pwd`
2. Projektwurzel
3. `git status --short`
4. aktuellen Branch
5. zentrale Projektdateien
6. README und weitere Projektdokumentation
7. Programmiersprachen und Frameworks
8. vorhandene Tests und Startbefehle
9. betroffene Komponenten

Bei der ersten Arbeit an einem Projekt führe einen vollständigen Bestandscheck durch. Bei späteren Aufgaben prüfe mindestens den Git-Status und alle betroffenen Bereiche.

## Arbeitsqualität

- Keine Annahmen als Fakten darstellen.
- Keine simulierten Funktionen als fertig melden.
- Bestehende Änderungen nicht überschreiben.
- Änderungen minimal und nachvollziehbar halten.
- Tests ausführen und Ergebnisse offen berichten.
- Kein Git-Push oder Deployment ohne Freigabe.
